# Encoding / Decoding Repo

A simple Python toolkit for encoding and decoding text files.

## Supported formats
- Base64
- Hex
- Caesar cipher
- SHA-256 hash (encode only)

## Usage

### Encode

# Advanced Encoding / Decoding Toolkit

A Python-based toolkit for encoding, decoding, compression, and batch processing.

## Features
- Base64
- URL-safe Base64
- Hex
- Caesar cipher with adjustable shift
- SHA-256 hashing
- Optional zlib compression
- Batch processing for folders

## Usage

### Encode a file
```bash
python toolkit.py encode -i input.txt -o encoded.txt -m base64
