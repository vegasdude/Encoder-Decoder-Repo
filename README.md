# Encoding / Decoding Repo

A simple Python toolkit for encoding and decoding text files.

## Supported formats
- Base64
- Hex
- Caesar cipher
- SHA-256 hash (encode only)

## Usage

### Encode
```bash
python encoder.py -i input.txt -o encoded.txt -m base64
